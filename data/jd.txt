岗位名称：AI Agent 开发实习生（大模型应用方向）

岗位职责：
1. 参与公司 AI Agent / 智能助手产品的开发，负责 Prompt 设计、工具调用（Function Calling）与多轮对话流程编排；
2. 参与 RAG 知识库问答系统的搭建与优化：文档解析、切分、向量化、检索与重排；
3. 对接大模型 API（DeepSeek / OpenAI 等），完成结构化输出与业务逻辑集成；
4. 搭建简单评测集，持续评估并迭代 Prompt 与检索效果；
5. 撰写技术文档，参与代码评审，与产品/算法团队协作。

任职要求（必须）：
1. 熟练掌握 Python 编程，能独立完成脚本与接口开发；
2. 有调用大模型 API 的实际经验（DeepSeek / OpenAI / 通义等均可），理解 Token、temperature、结构化输出等概念；
3. 理解 RAG 基本链路（文档切分 → 向量化 → 检索 → 生成），有相关实践更佳；
4. 理解 Agent 概念：Function Calling / 工具调用 / ReAct，或使用过 LangChain / LangGraph / Dify / Coze 任一框架；
5. 有 Prompt 工程经验，懂得用评测驱动迭代。

加分项：
1. 有可展示的 GitHub 项目或线上 Demo；
